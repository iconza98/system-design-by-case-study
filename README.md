# System Design by Case Study

An engineering study guide that takes apart fifteen real-world systems — Twitter, WhatsApp, YouTube, Uber, Instagram, Airbnb, Redis, Spotify, Tinder, Zoom, Figma, Cloudflare, PayPal, Lyft, and Bluesky — to show what each had to solve, the architecture it arrived at, and what it gave up to get there.

Rather than asking you to memorize architectures, each chapter teaches the underlying reasoning: requirements, back-of-the-envelope math, the "hard part," explicit trade-offs, and the patterns that transfer to new problems. Scale figures are dated and cited, and stale or unsourced claims are flagged.

**Contents**
- **Part I – Foundations:** the scaling ladder, estimation, and a pattern catalog
- **Part II – Case studies:** fifteen systems, with a suggested reading path
- **Part III – Reference:** pattern index, stale-facts appendix, numbers, and a study plan
